# Moat Momentum · Screener (four 2×2 groups) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Action › Screener page: master filter, adjustable risk pre-screen, four 2×2 groups with side box and three lists each, and an overlap section, from live 12-month data.

**Architecture:** Python (`mm_screener.py`) computes per company the raw risk measures and each group's X/Y now and at the previous 4 quarter-ends, written as a `scr` block in `site_data.js`. Everything that depends on user choices (filters, risk thresholds, percentile ranks, the three lists, overlap) runs in the page's JavaScript, so it updates instantly.

**Tech Stack:** Python 3.10 (`.venv`), pandas, numpy, unittest; vanilla JS/SVG in `output/moat_momentum.html`.

**Spec:** `docs/specs/2026-11-04-screener-design.md` (reading copy `output/screener_spec.html`). Binding.

## Global Constraints

- AGENTS.md: no commit/push until Jitti types save; each task ends with `.venv/bin/python -m unittest discover tests`. No keys or paid data. Every number shows source and date.
- Constants (spec §4–5): interest cover ≥ 3.0×, net debt ÷ EBITDA ≤ 3.0×, operating cash flow ÷ debt ≥ 0.20; Group 1 lines x 0.10 / y 0; Group 2 lines x 0.50 / y 0.09, return on new capital only when capital grew ≥ 10% over 12 quarters; Group 3 lines x 0.10 / y 0; Group 4 lines = medians over the whole universe; lists of 25; trend = now + 4 quarter-ends (±20 days).
- Past prices: Yahoo month-end close of the quarter's last month × later splits undone (`split_factor_after`) × cover-page shares filed by that point's filing date (`cover_at`); "now" uses `prices_daily` (yesterday's close).
- Untested screening tool: say so on the page. Scenarios, Proof, Track record unchanged. Site opens on Screener.
- Light, dark, 375 px checked in the browser; no console errors.

## Review Focus

1. Net-cash company with no interest expense: must pass all three risk checks, not be "not tested". Test in Task 1.
2. Company with no point 4 quarters back: must not enter lists ② or ③ (no change), may enter ①. Test in Task 3 (JS check).
3. Ticker split between the past quarter-end and today (e.g. a 10:1 split): past earnings yield must use the undone price. Test in Task 2.
4. Industry multi-select plus risk filter leaving 0 companies in a group: charts and lists show an empty-state message, no error. Check in Task 4.
5. Very long company names and 4 charts at 375 px: no horizontal page scroll; side box drops below the chart. Check in Task 4.

### Task 2: Group measures, now and 4 quarters back

**Files:** Modify `src/mm_screener.py`; Test `tests/test_screener.py`

- Produces:
  - `group_series(panel) -> DataFrame` adding per panel row: `g1x` (3-yr growth), `g1y` (roic_ttm − 0.09), `g2x` ((ic − ic lag4) ÷ nopat, nopat > 0), `g2y` ((nopat − nopat lag12) ÷ (ic − ic lag12) when ic − ic lag12 ≥ 0.10·|ic lag12|), `g3x` (= g1x), `g3y` (gross_margin − gross_margin lag4), `g4x` (= roic_ttm).
