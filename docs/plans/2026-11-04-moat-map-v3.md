# Moat Momentum v3.0 · Moat Map and Expectation Gap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Moat Map (ROIC above hurdle vs 3-year growth, with trails and movement rules R1–R3) and the Expectation Gap (reverse DCF), test R1–R3 once on 2021–2023, and ship them as new views beside v1.1 and v2.0.

**Architecture:** Pure functions for the reverse DCF and multiples; a positions module built on the existing TTM panel (`mm_quarterly.ttm_panel`) and universe/gate (`mm_signals.signals_at`); one test script writing `v3_test.json`; the live run adds a `moatmap` block to the site data, and the static page draws the scatter in SVG.

**Tech Stack:** Python 3.10 (`.venv`), pandas, numpy, unittest, yfinance (prices, already used); one HTML page with vanilla JS/SVG.

**Spec:** `docs/specs/2026-11-04-moat-map-v3-design.md` (reading copy `output/moat_map_v3_spec.html`). Read it before any task; its formulas are binding.

## Global Constraints

- AGENTS.md: no commit or push until Jitti types save; each task ends with the full test run `.venv/bin/python -m unittest discover tests`. No keys, tokens or paid data in any file. Every number shown has a source and date.
- Point-in-time: a date D uses only facts with `filed <= D` and, in the back-test, the Yahoo adjusted close of the last month-end **before** D.
- Fixed constants (spec §2–4): hurdle 0.09; growth line 0.10; R2 distance fall ≥ 0.05 and distance now ≤ 0.10; reverse DCF horizon 10 years, discount 0.09, terminal growth 0.03, tax 0.21, scan −0.20 to +0.60 in steps of 0.001; gap colour cap ±0.20; market-value sanity 0.002–200× revenue.
- Test dates: 2021-03-15, 05-15, 08-15, 11-15 … 2023-08-15 (11 dates). Pass: pooled rule-list compounder rate ≥ 2.0× rest **and** higher than rest in each of 2021, 2022, 2023. No re-tuning after results.
- v1.1 stays the main ranking; v2.0 stays experimental; v3.0 adds views only.
- Plain-language English UI text; light, dark and 375 px phone width checked in the browser before done.

## Review Focus

1. A company with no point 4 quarters earlier (new listing, missing 10-Q): must not appear in R1/R2 and must still count in "rest". Test in Task 3.
2. Cash-rich company with EV ≤ 0, or negative ROIC: implied growth n/a, grey dot, never in R3. Test in Task 1/2.
3. No Yahoo price for a ticker at a back-test date (delisted, renamed): no gap, excluded from R3, still in "rest" with its label. Test in Task 4.
4. Extreme x or y (ROIC 400% after buybacks, revenue from near zero): axis capping must pin, not drop, the dot. Test in Task 6 (JS pure function check in browser).
5. 1,800 SVG dots plus trails in dark mode and at 375 px: readable, no horizontal page scroll. Check in Task 6.

### Task 3: Moat Map positions and rules (`mm_moatmap.py`)

**Files:** Create `src/mm_moatmap.py`; Test `tests/test_v3.py`

**Interfaces:**
- Consumes: `ttm_panel`, `lag_q` (Task-independent, existing); `signals_at(facts, companies, date, settings, live, panel=None)` for universe rows (`cik, ticker, industry_group, gate_removed, end`).
- Produces:
  - `positions(panel: DataFrame) -> DataFrame` adding to each panel row: `x` (3-yr growth, needs revenue 12 quarters earlier > 0), `y` (= roic_ttm − 0.09), `d` (distance), `x_4, y_4, d_4` (values 4 quarters earlier), trail columns `x_t1..x_t5, y_t1..y_t5`.
  - `classify(rows: DataFrame) -> DataFrame` given rows with `x, y, d, x_4, y_4, d_4, industry_group` for **one date**: adds `ind_med_x`, `top_right`, `top_right_4`, `quadrant` (one of "Compounder", "Profitable, slow", "Growing, below hurdle", "Neither"), `r1`, `r2`, `moved` (= d_4 − d).
  - `map_at(facts, companies, date, settings, live, panel=None) -> DataFrame`: universe rows at `date` (latest panel point filed ≤ date, end ≥ date − 548 days) joined with positions and classify.
  - `top25(rows, rule_col) -> DataFrame`: rows with rule true and `~gate_removed`, sorted by `moved` desc then `y` desc, first 25.

- [ ] **Step 1: Failing tests** (synthetic panels):
  - `test_x_y_d`: revenue 100 → 133.1 over 12 quarters → x 0.10 ± 1e-9; roic 0.12 → y 0.03; x 0.06, y −0.02 → d 0.06.
  - `test_top_right_needs_industry_median`: two companies in one group, x 0.12 and 0.30, y ≥ 0 → median 0.21 → only the second is top_right.
  - `test_r1_entered`: top_right now, not a year earlier → r1 True; missing earlier point → r1 False.
  - `test_r2_thresholds`: d_4 0.14 → d 0.09, x and y both up → r2 True; d_4 0.13 → d 0.09 (fell 0.04) → False; d 0.11 → False; x up, y down → False.
  - `test_top25_order_and_gate`: gate_removed excluded; order by moved, ties by y.
- [ ] **Step 2:** Run; FAIL. **Step 3:** Implement. **Step 4:** PASS; full suite. Then a real-data check: `map_at(..., "2023-05-15", live=False)` prints counts per quadrant, R1, R2 and the share with x and y present; record in notes.
