Recommendation: A + C with stated bounds, now; D later only if needed

  1. Prices from Yahoo for every pick that still trades (about 69% of shortlist picks).
  2. For picks that stopped trading, read the SEC filings to see what happened, then run the test three ways:
    • Neutral: the missing stock earned the S&P 500 return after its last filing.
    • Worst case: a failed company counts as −100%.
    • Acquired: counts as the S&P 500 return, which ignores any takeover premium, so it is conservative.
    If the conclusion is the same in all three, the missing data does not change it.
  3. Compare with the S&P 500, an equal-weight universe (same Yahoo + bounds method) and the AQR Quality Minus Junk factor, to see whether the screen adds anything beyond a known quality factor.
  4. Report CAGR, excess return, volatility, maximum drawdown, hit rate, turnover, results per year and per sector, with the survivorship bound shown next to every number.

Time: A + C ≈ 2–3 hours of work, so it fits before Wednesday. B through the desktop API would need you to run IBKR's TWS or Gateway on your Mac and enable the API, so it is not for this week.

Expectation: the fundamental test (step 5) found that picks were good companies whose improvement tended to fade. A market test may show quality-like returns, but the pitch should not expect alpha from "strengthening" until it is shown.
